# Maple：覆盖上传、视频时长与下拉关闭

日期：2026-10-25。范围：当前工作区 Maple H5；共用 Upload API 同步 Cedar。保留现有 Form / FormItem / 字段编辑器，未新增业务上传组件。

## 本轮实现

| 能力 | 已实现的行为 | 边界 |
| --- | --- | --- |
| 覆盖上传 | `reupload` 开启逐项替换；`replace(file, replacement?)` 支持单文件选择或传入 File；新 UID 原位替换 | 不是先删后加。取消、校验失败、beforeRemove 拒绝、目标过期均保留原项；总大小和数量扣除旧项 |
| 受控模型与请求 | 替换是原子模型提案，发出 replace / change，不发出 remove；父级接纳后旧请求失效 | 不删除服务端文件。新文件上传失败后可重试，不自动回滚旧文件。父级延迟接纳沿用原有队列语义，组件持有候选资源直至接纳或生命周期清理 |
| 视频时长 | `duration` 为秒；显示 mm:ss / h:mm:ss，0 有效，未知隐藏；本地 File 自动读取 | 最多等待 5 秒；支持缺少 duration 的本地 WebM 尝试定位尾部。成功、失败、中止和卸载清理 URL/监听/计时器。远端回显由业务提供 duration，不为此主动请求远端视频 |
| 视频与附件展示 | 图文/卡片角标、文本列表时长、原有视频预览；预览继承 popupContainer | 卡片文字层不再挡住预览点击。样例视频为本地生成的约 2 秒无声片段，无外部素材 |
| 下拉关闭 | 底部 Popup `swipeToClose` / `swipeThreshold`，指定 `data-popup-swipe-handle`；ActionSheet 转发，字段编辑器启用 | 默认 40 布局 CSS px，补偿父级缩放；仅足够向下的头部手势触发。短拖动、上/横向、取消、正文与交互控件不关闭；受控拒绝会回原位 |
| 表单事务 | 头部下拉走原有 cancel，未确认草稿丢弃；异步确认 pending 禁用手势 | 不引入第二套提交或校验流程；原关闭按钮、Esc、遮罩和焦点恢复保持使用现有机制 |

## 四套主题的完整表单

Alps / Firefly 的亮暗完整表单均包含：本地成功、首次失败后重试、慢速取消、文件大小/数量限制、替换守卫、三种附件布局、2 秒视频样例、头部下拉取消、四边 inset 与横屏模拟。

视频角标圆角：Alps 4px，Firefly 8px；亮色背景分别为 Horo 实采的黑色 0.3 / 0.36，文字白色。暗色为 Maple 适配的黑色 0.72、白色文字。新增五个 duration 公开样式角色，在 Cedar/Maple 共用契约登记，生成 Token 目录同步更新。

完整表单使用 data-url 保留本地附件草稿；生产上传成功后应由业务写入服务器 URL。object-url 继续遵循创建组件及预览引用的生命周期，这次没有改变其全局默认值。

## 验证

浏览器源码集成涵盖两套亮色实采角色、四套主题安全区/横屏、选择和日期时间事务，以及四套主题替换/真实视频元数据/预览/下拉取消。新增横屏检查验证缩放后的短拖动不会关闭，足够下拉会取消草稿，底部仍为 21px 且嵌套消费为 0。

组件控制器验证包括单项/总量限制、异步守卫拒绝、受控拒绝、外部删除竞争、旧请求晚到、取消选择、元数据成功/错误/中止/超时清理，以及手势方向/阈值/控件排除/pending 中断。

最终结果：Maple 上传/Popup/ActionSheet 共 139 项单测通过；Cedar Upload 共 68 项通过。源码完整表单 14 项浏览器用例通过，新增四套主题用例又完成横屏复核；最终生产文档 4 项通过，实际执行了添加视频、替换附件和下拉取消草稿。两端类型检查、定向 lint、共享 Token 契约、3 份 Token 目录和组件规范检查通过。更新了 5 份因新增节点/标题拖动区域发生预期变化的快照。

Maple 库最终构建成功，文档 1482 个 SFC 检查通过，Vite 生产构建成功。本地 5500 返回 200。完整图像位于 Maple `artifacts/brand-form/`，部分归档为：[Alps 暗色视频时长](evidence/alps-dark-video-duration-2026-10-25.png)、[Firefly 亮色视频时长](evidence/firefly-light-video-duration-2026-10-25.png)、[Firefly 暗色横屏取消后](evidence/firefly-dark-swipe-landscape-2026-10-25.png)。

## 仍需单独实现

视频播放器业务参数、Horo Calendar 的时区协议、多月虚拟滚动、line 模式，以及基础 Popup 全关闭原因异步拦截仍有差异。这三项已补能力不代表所有私库 API、所有 App 桥接或所有浏览器版本都已等价；亮色有实采证据，暗色是 Maple 适配版。

后续更新：日历时区、多月虚拟滚动、line 模式及 Popup 异步拦截已在下一轮实现，验收和协议边界见 [完整表单差异报告第 8 节](horo-maple-form-gap-2026-10-25.md)。视频播放器业务参数仍需独立评估。
