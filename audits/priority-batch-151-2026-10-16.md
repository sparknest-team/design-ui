# 第一百五十一批：Scheduler 隐藏日期拖动与月历更多事务

## 源码开发站真实交互

使用 Cedar4185 `/components/scheduler/?audit=151`，只操作现有本地合成数据。Scheduler只有Cedar提供，不虚构Maple对应验收。未注入事件或模型。

### 隐藏周末与指定星期

1. 隐藏周末初始开启；勾选隐藏周三后，月历只剩周一/二/四/五，周三评审不显示；数据计数仍3。取消隐藏周三后评审重现。
2. 打开跨周末项目，详情为全天、2026-09-18至2026-09-22（结束不含）；取消不改值。
3. 使用真实完整指针手势，将9月18日周五卡片拖到下周一21日单元格。出现日程已更新，任务显示在21—24日。重新打开详情，起止是2026-09-21至2026-09-25，四天持续时长保留，没有按相邻可见列错误地只移动一天。
4. 取消详情，撤销成功移动，重新打开详情恢复18日至22日。取消后解除隐藏周末，19日周末值班10:00重现，完整数据仍3条，跨周末项目显示在18—21日。

### 月历更多日程

1. 在拖选/更多日程Demo切换月视图。9月22日直接显示任务1/2及还有3项；Enter打开Popover，内容完整包含任务1—5（09:00至13:00），不是只列被折叠的三项。
2. 对13:00任务5按Enter进入详情，Popover关闭。详情为任务5、2026-09-22 13:00—14:00。
3. 标题改为合成草稿后取消；重新打开更多列表仍五项、名称仍任务5。再次进入详情确认标题未保存，再取消。
4. 对还有3项按Escape，aria-expanded变false；空格重开仍五项。点击拖选排期切回周视图，Popover内容节点数为0，五条原任务仍存在，没有因进入详情/取消而创建额外日程。
