# 第九十四批：两端 Checkbox 异步请求取消竞态

## 改动

- Cedar 与 Maple 各自的 Checkbox 异步选项 Demo 改用 800ms 本地延迟模拟待完成请求；加载中可见提示，移除选项会清除待完成定时器。再次加载会取消前一次待完成加载；组件停用或卸载时也清理定时器，避免示例在离开页面后继续写入。
- Cedar 中文与 Maple 中英文文档说明待完成加载的取消语义。组件运行时代码、公开 API 和菜单入口均未变化；菜单原有 Checkbox `[已同源]` 状态保持正确。

## 新构建站真实交互

- Maple `?audit=94-built` 和 Cedar `?audit=94-built` 均由本批新构建文档站加载。两端实际点击“加载选项”，在加载提示可见时立即点击“移除选项”；超过 800ms 后选项仍为零，模型仍是 `['remote']`，加载提示已消失。
- 两端随后再次点击“加载选项”，等待异步设备出现；remote 的原生输入为 checked，设备 A/B 可用，停用设备为原生 disabled。取消后重新加载没有丢失模型值。
