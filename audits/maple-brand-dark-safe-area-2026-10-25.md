## 同页安全区模拟

完整预约表单中可以设置 top / right / bottom / left（0–120 CSS px），选择竖屏 390×720、横屏 844×390 或四边归零。默认缩放到容器宽度，也可选择原尺寸并横向查看。测量始终以原始 CSS px 计算，缩放不会改变 inset 协议。

页面壳层只消费上、左、右；字段区独立滚动；底部提交区消费 bottom 一次。提交区内再嵌套一个 SafeArea，其 padding-bottom 必须是 0。斜纹直观显示占用的安全区。

所有字段编辑层挂载到模拟视口的 HTMLElement；它位于已消费的页面壳层之外，所以单独继承原始 inset。左右/底部 padding 为对应 inset 加面板基础留白（默认 8px）。例如横屏左右 44、底部 21 时，面板为 52 / 52 / 29px。宿主把 bottom 更新为 0 时，提交区为 0，面板仅保留原有 8px。

测量区检查页面、提交区、嵌套安全区及已打开的面板，显示“检查通过：未重复留白”。CSS 变量仅写在该示例的模拟视口上；不调用全局 SafeArea.setInsets，也不影响文档和其他表单实例。关闭示例不留下全局覆盖。

模拟视口通过容器尺寸、滚动与局部 fixed 定位验证布局；不能代替真实设备旋转、WebView 键盘、系统状态栏或原生 SDK 的集成验收。
