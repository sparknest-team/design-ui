# 空值文档与示例分组

日期：2026-10-29。范围为上一轮 emptyValue / emptyValues / emptyText 的文档与示例；没有修改组件运行逻辑或受控逻辑。

## 信息组织

- 指南先解释属性选择，再按五类场景提供操作与预期结果，最后解释继承、领域边界、校验与受控身份。
- 清空与手动删空进入 Input「值模型与交互」。
- 哨兵、有效 0 与清空恢复 0 进入 InputNumber「数值输入与格式」。
- 合法空字符串、null / undefined / 数组清空进入 Select「值模型与联动」。保留原示例的单选工厂、多选数组清空，并把原本混入 Select 的数值场景移到 InputNumber。
- required 空标记进入 Form「校验与提交」；emptyText 和三级继承进入 Form「字段呈现与交互」。
- 组件属性定义移入 API 区；中英文分组配置与 Maple 手机入口同步。
- 五类场景分别有两端中英文 SFC，共 20 份场景文件。指南、组件正文、手机入口和源码面板引用同一份文件，指南不再复制可执行 Vue 代码。
- 核对源码后修正 Input nullable 模型说明，以及 Select 多选并非一律忽略 emptyValue 的过时说明；更新公共 API 翻译字典，防止后续生成恢复旧文案。
