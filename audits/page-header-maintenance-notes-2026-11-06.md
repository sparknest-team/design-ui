# PageHeader 内部维护说明

从 Cedar / Maple 的中英文 PageHeader 公开文档移入，保留供组件维护者参考。

两端各自保存完整源码，不引用公共核心，不共享组件实例或响应式状态；修改时同步维护两份实现。主体、Props、关键样式及配对测试纳入只读源码一致性检查，主题 token 和安装入口各自维护。

Cedar 内部类名曾由 `c-page-header-xxx` 调整为 `c-page-header__xxx`；图标资源由各库本地提供。这些实现和迁移信息不属于对外组件使用说明。

返回按钮的点击、键盘操作及 `back` 事件继续在组件文档中说明。实际消费的组件 CSS 变量及默认值保留在各平台的 `CSS Variables` 表格中。
