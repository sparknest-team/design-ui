## 已修复

- Maple 根入口生成器补充 `fieldLoadingModes`，与组件入口和现有文档一致；主题预设的 Ref 显式使用变量记录类型，允许切换明暗和品牌预设。
- 修正 Breadcrumb、Image、ProgressGroup、Signature、Tabs 测试中的原生属性、DOM、事件参数和回调推断，保留原有行为断言。
- NoticeBar 手机页补齐暂停滚动示例及英文版本；ThemeProvider 手机页按文档分组规则生成。
- 中英文生成同步当前用法，修正事件参数表头、标识符内代码标记、尾随空格及中文“默认”表头；保留变量职责表，去除重复默认表。相关回归接入两库文档流水线。
- 清理 Alert 旧 API 对照、Switch 旧变量保留说明、NavMenu 内联迁移词条和 ConfigProvider 失效主题示例引用。另复查并改写 34 页当前用法，移除 Table/Tree 的废除属性行及 Date 的旧时间面板变量表；相关检查防止生成器重新带回。
- Tabs、AutoComplete、Time 的同源检查使用语法规范化，保留类型、字面值、事件及绑定覆盖顺序；回归包含行为改变的反例。Tabs 本地语言适配并入已有配置入口，保留禁止 platform 模块的门禁。
- Maple 时间面板的内部变量和样式归入独立私有模块，恢复 PickerField 两端的共同声明；变量消费测试验证新样式入口，内部变量不作为公共 API 发布。
