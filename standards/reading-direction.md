# 阅读方向

公共阅读方向使用 `dir: 'ltr' | 'rtl'`，省略时继承；`orientation` 与 `direction` 继续表示朝向、排列或运动，不承担阅读方向。Cedar ConfigProvider 与 Maple LocaleProvider 提供方向作用域，原生 DOM 的局部 dir 同样有效。上下文与 DOM 必须一致，支持 RTL 内嵌 LTR 和运行时切换。不要从 locale 强制推导 dir；语言与布局方向分别配置。

组件布局使用逻辑 CSS；明确表示物理位置的 left/right、屏幕坐标、Badge 角落保留语义。水平键盘、指针、滚动、手势与动画统一消费解析后的方向。垂直轴不因 RTL 自动倒转；数字、代码、地图、签名、照片等内容不整体镜像。

use 包的 useDirection 解析最近的原生 dir，回退到注入方向，再回退 LTR；provideDirection 不修改 document。每个 ownerDocument 共享一个 dir 观察器，卸载、停用后退订。SSR 依赖明确的作用域配置，不访问 document。`dir=auto` 可用于内容，行为组件使用解析后的 ltr/rtl。

弹层在实际挂载根节点写入来源方向，定位的 start/end 按方向解释；left/right 为物理侧。Portal 不可只依赖挂载目标继承方向。方向变化后更新位置、箭头及动画原点。函数式弹层应使用显式上下文或 document 方向，不能借用其他应用实例。

文档导航提供 LTR/RTL 按钮：显示当前状态，aria-pressed 表示 RTL，按钮标签说明目标方向；刷新保留偏好，语言切换不改变方向。移动端 iframe 通过同源存储和受限消息同步，组件预览与文档页使用相同方向。代码块保持 LTR。

每个组件族至少验收 LTR、RTL、双向嵌套及动态切换；行为组件覆盖鼠标、键盘、触摸和垂直模式；弹层覆盖 Teleport 与自定义容器；基础设施覆盖 SSR 和销毁清理。静态扫描只是遗漏线索，不等于支持率或视觉通过。

横向滚动内部区分两套坐标：滚动条拇指使用距物理左侧的坐标；Table/VirtualList 同步与运行时切换使用距阅读起点的非负距离，经集中函数转换为原生 scrollLeft。虚拟行的纵向定位不得重置横向位置。跨容器的吸底区域明确传递来源方向。

Split 的 size 始终属于第一个面板，横向随阅读方向排列；ResizeBox 的 left/right 手柄仍为物理边。拖动事务在方向/朝向变化、禁用、停用或卸载时取消，释放 ownerDocument.defaultView 上的监听并恢复之前的光标。观察器内不直接写入会影响被观察节点的布局，使用按帧合并测量。

Scheduler 的日期、时间轴比例和资源数据保持领域顺序；只在横向时间与屏幕坐标之间转换阅读方向。事件、预览、依赖起止端点、拖动吸附和滚动定位必须使用一致规则，纵向时间保持向下。虚拟视口重建后再恢复缩放日期锚点，停用或卸载取消延迟帧。默认布局使用逻辑起点；公开自定义布局中的 left 保持物理语义。使用 Unicode 方向图形时注意原生双向镜像，显式选择的箭头需隔离文本方向，避免二次反转。

输入组件保留原生输入节点与浏览器编辑语义，方向切换不重建编辑器或反转业务字符串/数组。浮动提示以实际内容列的阅读起点测量偏移，并在原生 dir 变化而尺寸未变化时重测；缩放原点跟随阅读方向。选择框独立使用默认 start；显式 textAlign 的 left/right 为物理对齐，不能映射为随方向翻转的 flex-start/flex-end。打开弹层的来源方向更新与点击切换按钮产生的正常外部关闭行为应分别测试。输入法自动化仅验证合成事件协议，不替代系统输入法真机验收。

Form/FormItem 的 contentAlign 使用 start/end/left/center/right，labelAlign 使用 start/end/left/right。默认内容 start、水平标签 end，在 LTR 下保持原位置；显式 left/right 始终为物理侧，并对文本与 flex 使用一致规则。逐字段配置优先于 Form，标签列显式样式优先于默认对齐。Radio 横向键消费事件目标的当前阅读方向，上下键和 Home/End 保持业务顺序并跳过禁用项；Checkbox Space 与 Switch Space/Enter 不因方向而改义。Switch 选中状态从阅读起点向终点移动，不能通过方向切换改变业务值。

层级选择的左右键映射为“进入子级/返回父级”，不改写原始 KeyboardEvent；从事件目标解析当前方向，跳过禁用子项并保持路径/值数组顺序。搜索输入的横向键继续交给原生编辑器。展开图形只镜像方向图形，列分隔线使用逻辑终点。清空已关闭选择器的最后值时，同时清理旧键盘路径。补全候选更新可能重绘其 Input：组合期间读取原生缓冲而非旧模型值，旧选区恢复任务不得覆盖新组合；组合结束后沿用正常提交流程。光标行为应与同方向原生输入作对照，不能假定 RTL 的左右键总是增加或减少字符串索引。

日期和时间保留领域顺序：范围值仍为 `[开始, 结束]`，时间文本、跨日与时区规则不因 RTL 反转。分页日历的左右键按视觉方向移动焦点，上下键移动一行；Home/End 定位当前行边界并跳过禁用项，边界不自动翻页。时间左右键在列间移动焦点；Cedar 上下键与 Home/End 只移动焦点，Maple 原生滚轮的垂直选值语义保持不变。方向切换不能产生选值或确认事件。范围高亮半线、边界圆角与前后翻页图形跟随方向，公开命名的快捷区 left/right 保持物理侧；只镜像方向图形，不镜像文字。

按钮组的拼接边界由组的阅读方向决定，不能由子按钮的局部文字方向决定；横向首尾圆角、text 分隔线、outline 重叠边必须使用一致的组坐标。方向作用域内的物理 CSS 可用于明确组坐标，不视为遗漏。单个按钮保留完整外轮廓，纵向组不倒序；普通按钮组保留原生 Tab/Enter/Space，不新增 toolbar 的左右键语义。SplitButton 主动作与菜单动作按阅读起止排列，下拉图形不镜像，菜单继承来源方向并归还焦点。Space 的 row/column 是排列轴，size 数组是行/列 gap，均不改写数据；Divider 的水平 start/end 随阅读方向、垂直 start/end 保持上/下，沿线和线外间距按逻辑轴解释。

全量收尾继续区分领域与布局：验证码和数字键盘保留 LTR 字符/数字顺序，外围逻辑对齐可以跟随 RTL；图片集合的导航和轨道随阅读方向，图像、缩放/旋转和放大平移保留物理坐标。方向变化取消进行中的预览手势，但不更换图片或清空缩放。NoticeBar 从阅读终点向起点滚动，不对文字做 scaleX。Layout.Sider、Drawer、Collapse 图标位置和 Notification 的显式 left/right 保留物理含义，安全区按设备物理边缘计算。默认分页/返回图形跟随方向，自定义图形槽位由调用方决定。
