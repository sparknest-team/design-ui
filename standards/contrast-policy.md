# 颜色对比度提示

颜色对比度检查用于提供建议，不阻断 PR 合并。现有文字 4.5:1、图形/焦点 3:1 等目标保留为提示阈值；定制或手动调整的配色不自动改写，也不为了通过检查而强制修改色阶。

主题检查使用 `bin/contrast-report.mjs` 记录低于建议值的颜色对，输出 GitHub Actions warning、总数量、最低实测对比度及最多 8 个示例。提示保留完整测量值，不将略低于阈值的结果四舍五入成“达标”。

颜色数据格式、CSS 变量解析、主题变量映射与覆盖行为仍为硬检查。类型、构建、SSR、交互、运行时依赖和包内容等 Quality 门禁不受此策略影响。
